Pk server bot - Privacy Policy

Last updated: 2026-11-23

1. Who we are and what this covers

Pk server bot (the "Bot") is operated by the Discord user kilog257 ("we" or "us"). This policy explains what information the Bot reads, stores and shares when it runs in a Discord server and when someone uses its web dashboard.

It does not cover Discord itself, which has its own Privacy Policy (https://discord.com/privacy). By adding the Bot to a server or using its features, you agree to this policy and to our Terms of Service.

2. What information the Bot handles

The Bot receives information from Discord about the servers it is in: user IDs, usernames, nicknames, avatars, roles, channels, voice activity, server invites and message content. It reads message content to run automod and award XP. This table shows what is kept, feature by feature.

Feature	What it handles	What the Bot keeps
Server settings	Server ID, channel, role and category IDs, your message texts, colours and image links	All of it, until deleted
Levels and XP	Message activity, voice time	User ID, XP, level, time of last XP gain, voice minutes
Automod	Message text, checked for invites, links, blocked words, mass mentions and capital letters	Nothing. A removal notice naming the author and reason is posted to the server's log channel
Moderation	Warnings and mod notes written by staff	Member ID, moderator ID, reason or note, date
Invite tracker	Server invites and who joins	Per inviter: joins and leaves. Per member: who invited them
Tickets	Opener, ticket type, who claimed it, timestamps	Kept while the ticket is open, then deleted
Ticket ratings	Stars and optional comment from the member	Opener ID, handler ID, stars, comment, date. Newest 2,000 per server
Ticket transcripts	Every message in a closed ticket, with author name and ID and attachment links	Nothing. The file is posted to the server's log channel only
Confessions	Confession text and the sender	Only a running number. The text is posted publicly without a name. The sender's name and ID go to the server's staff-only log channel
Starboard, suggestions, announcements, changelog	Message text, author name and avatar, first image	Nothing. Posted in the server's channels
Welcome and goodbye cards	Member name and avatar, your background image link	Only the background link. The card image is not saved
Dashboard	A login cookie named pk_auth, set only after the correct password	The cookie lives in your browser. No other cookies or tracking
Technical logs	Start-up messages and error details	Kept on the host, may include Discord IDs. No message content
Dashboard login. If you log in to our web dashboard with Discord, we use Discord's OAuth service to read your Discord user ID, username and avatar, and to check which servers you manage. We use this only to confirm you have permission to manage the server you select. We do not store your Discord access token and we do not receive your password or email address.
3. How we use it

We use this information only to run the features listed above:

To give out XP, levels and role rewards
To enforce automod and anti-raid rules chosen by the server
To keep warnings, notes and invite counts that staff asked the Bot to track
To run tickets, ratings, confessions and the other features a server turns on
To show server admins their own settings and statistics in the dashboard
To find and fix errors

We do not sell your information, show ads, or build profiles for marketing. We do not use message content to train AI models.

4. Where it is stored, who can see it, and who we share it with

Storage. Data is kept in a file on the server that hosts the Bot, which is run by the operator. The Bot does not use any outside analytics or advertising service.

Who can see it.

Server admins and staff see what the server's own features show them: warnings, notes, ticket logs and transcripts, confession logs, ratings and invite counts for their own server.
Anyone with the dashboard password can see the settings and statistics of every server the Bot is in. Only the operator holds this password.
Staff of a server can see who sent a confession, because it is written to the staff-only log channel the server chose. Members of that server see only the anonymous post.
Posts the Bot makes in a server's channels are visible to whoever can see those channels.

Sharing. We do not sell or rent your information. The Bot runs on Discord, so what it sends and receives passes through Discord, which has its own Privacy Policy (https://discord.com/privacy). We may share information if the law requires it, or to protect people's safety.

5. How long we keep it, and deleting it
Server settings, XP, warnings, notes, invite counts: kept until a server admin deletes them, or until the Bot is removed from the server and the operator clears that server's data.
Open ticket details: removed when the ticket is closed or the channel is deleted.
Ticket ratings: the newest 2,000 per server are kept.
Transcripts, confession logs and automod notices: these live in the server's own Discord channels, so the server controls how long they stay.
Technical logs: kept on the host and rotated or deleted from time to time.

To ask for deletion: contact the operator (section 9) with your Discord user ID and, if you can, the server concerned. We will delete what the Bot stores about you, except where we must keep it by law. Anything posted in a Discord channel must be removed in Discord by that server's staff or by you.

6. Security

The dashboard is protected by a password, and its login cookie is HttpOnly and sent only to the dashboard's own site. The Bot's token and password are kept in a private settings file on the host and are never shown to server members. No system is perfectly secure, and we cannot guarantee that data will never be lost or accessed without permission. If we learn of a breach that affects you, we will tell the affected servers where we can.

7. Children

The Bot is not meant for children under 13, or under the minimum age for Discord in your country. We do not knowingly collect information from them. If you believe a child's information has been stored, contact us (section 9) and we will delete it.

8. Your choices and rights
Server admins can switch features off in the dashboard, or remove the Bot, to stop it handling data for that server.
You can ask what the Bot stores about you, ask us to correct it, or ask us to delete it (section 9).
You can clear the dashboard cookie in your browser at any time.
Depending on where you live, you may have further rights under local privacy law, such as access, correction, deletion or objection. We will respond to such requests as the law requires.
9. Changes and contact

We may update this Privacy Policy from time to time, for example when we add a feature that handles new information. The date at the top of the page shows when it last changed.

Questions, or requests to see, correct or delete your information: message the Discord user kilog257.
